# SPL Informática - Website

Este é o repositório do site institucional da SPL Informática, uma empresa especializada em desenvolvimento web e consultoria.

## 🚀 Tecnologias Utilizadas

- React 18
- TypeScript
- Vite
- Tailwind CSS
- Lucide React (ícones)

## 📦 Pré-requisitos

- Node.js (versão 18 ou superior)
- npm (gerenciador de pacotes do Node.js)

## 🛠️ Instalação

"usar caminho cd app"

1. Clone o repositório:
```bash
git clone https://github.com/seu-usuario/splinformatica.git
cd splinformatica
```

2. Instale as dependências:
```bash
npm install
```

## 🔧 Comandos Disponíveis

- `npm run dev`: Inicia o servidor de desenvolvimento em http://localhost:5173
- `npm run build`: Gera a versão de produção do site na pasta `dist`
- `npm run preview`: Visualiza a versão de produção localmente
- `npm run lint`: Executa a verificação de código com ESLint

## 📁 Estrutura do Projeto

```
src/
├── components/         # Componentes React
│   ├── ui/            # Componentes reutilizáveis
│   └── ...           # Componentes específicos
├── styles/            # Arquivos CSS e estilos
├── App.tsx           # Componente principal
└── main.tsx          # Ponto de entrada da aplicação
```

### 📋 Componentes Principais

- `Header`: Barra de navegação responsiva
- `Hero`: Seção principal da página inicial
- `Services`: Lista de serviços oferecidos
- `Portfolio`: Galeria de projetos com filtros
- `About`: Informações sobre a empresa
- `Testimonials`: Depoimentos de clientes
- `Contact`: Formulário de contato
- `Footer`: Rodapé com links e informações adicionais

### 🎨 Componentes UI

- `SectionTitle`: Título padronizado para seções
- `Link`: Componente de link estilizado
- `ServiceCard`: Card para exibição de serviços
- `ProjectCard`: Card para projetos do portfólio
- `TestimonialCard`: Card para depoimentos
